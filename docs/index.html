MultiDeck

Keep several firmware on a microSD card and pick one on the touch screen. From the maker of RigDeck.

Waveshare ESP32-P4-WIFI6-Touch-LCD-7B · …
  1. Connect the board's USB-C port to this computer with a data cable.
  2. Press Install MultiDeck, pick the board's serial port, and follow the steps. Leave "Erase device" unticked: RigDeck's settings and log are kept.
  3. Copy firmware .bin files into a folder named firmware on a FAT32 microSD card and put it in the board.
  4. Tap a firmware on the screen, then Start.
Use Chrome or Edge on a computer to install from this page. This page needs HTTPS. Download .bin
Back to MultiDeck from any firmware: tap RESET, then straight away press and hold BOOT until MultiDeck appears. (Holding BOOT while pressing RESET puts the board in USB download mode instead: just tap RESET again.)

Which files work

Any ESP32-P4 application image: build/<project>.bin from idf.py build, or a full-flash release image (like rigdeck-1.0.0.bin from the RigDeck page). MultiDeck takes the app out of a full-flash image and checks chip, chip revision and size before copying anything. Up to 4 MB per firmware.

Optional: a text file with the same name (RigDeck.txt next to RigDeck.bin) gives the name on the tile (first line) and a short description (the next lines).

firmware/
  RigDeck.bin
  RigDeck.txt        RigDeck
                     FT8 / FT4 station, logger and control head.
  meshtastic.bin

The last two firmware started stay on the board and start at once next time, card or no card.
